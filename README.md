# Secure Login & Registration Interface

Week 1 project: Core UI Layouts, DOM Interactivity & Responsive Foundations.

A single-page front-end demo with switchable Log in and Register forms, built with plain HTML, CSS and JavaScript (no frameworks).

## Features
- Switchable Login / Register tabs with a sliding indicator and arrow-key support
- Real-time validation: email format, password length (8+ with a letter and a number), confirm-password match
- Show / hide toggle on every password field
- Accessible errors: `aria-invalid`, `aria-describedby`, live regions, and focus moves to the first invalid field on submit
- Responsive layout (two columns on desktop, stacked on mobile)
- Visible keyboard focus and `prefers-reduced-motion` support

## How to run
Open `index.html` in any modern browser. No build step is needed.

## Skills demonstrated
Forms, CSS Grid/Flexbox, client-side validation, DOM events, responsive design, accessibility.

## Notes
This is a front-end demo only. Form data is never sent anywhere.
